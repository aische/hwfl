# stdlib-list

Smoke example for the shipped `hwfl/*` pack (`hwfl/list`, `hwfl/option`,
`hwfl/string`).

```bash
cabal run hwfl -- check examples/stdlib-list
cabal run hwfl -- run examples/stdlib-list --workspace /tmp/hwfl-stdlib
```

Override the pack root with `HWFL_STDLIB=/path/to/stdlib` if needed.
