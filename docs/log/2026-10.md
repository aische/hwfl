# 2026-10

## 2026-10-06 — llm-simple 0.2 Phase 1–2

- Engine types now own ordered assistant content: `AssistantPart`,
  `ThinkingContent`, `ProviderOpaque`; `TurnAssistant [AssistantPart]`.
- `ProviderResult` treats `prParts` as authoritative; `prContent` /
  `prToolCalls` are smart-constructor projections. Cache counters added
  to `TokenUsage`.
- `Hwfl.Llm.Simple` maps llm-simple 0.2 `ContentPart`/`PartBody` and
  opaque metadata in both directions; `UnsupportedCapability` →
  `InvalidRequestError`.
- Snapshot JSON still used the legacy assistant shape until Phase 4.

## 2026-10-06 — llm-simple 0.2 Phase 3

- Agent rounds append `TurnAssistant pr.prParts` (tool and final-text
  paths); tool dispatch / author `text` use projections only.
- `turnVisibleChars` / transcript formatting count visible thinking +
  text + tool args/results; opaque payloads never rendered.
- `wireTurns` caps tool results without rewriting assistant parts; mock
  streams deltas in part order.

## 2026-10-06 — llm-simple 0.2 Phase 4

- Canonical assistant snapshot JSON is ordered `parts` (`text` /
  `thinking` / `tool_call`), with `thinking_opaque` and `provider_meta`
  for provider replay state. Legacy `text`+`calls` still decode.
- Author-facing `turnToPublicJson` (used by `valueToAeson`) omits opaque
  payloads; machine/snapshot codecs keep them for pause/resume.
- Migration fixtures under `test/fixtures/turns/`; `TurnSpec` covers
  decode, opaque round-trip, invalid tags, and public encoding.

## 2026-10-06 — llm-simple 0.2 Phase 5

- `ModelRates` parses optional `pricePerMillionCacheRead` /
  `pricePerMillionCacheWrite`; missing rates fall back to ordinary
  input (llm-simple-compatible).
- Cost uses ordinary input =
  `max 0 (input - cacheRead - cacheCreation)`, then cache rates.
- LLM close attrs add `token_cache_read` / `token_cache_creation`
  while `token_in` remains total input; redaction allowlists them.

## 2026-10-06 — llm-simple 0.2 Phase 6

- Checked-in `model-catalog.json`: `deepseek4flash` declares thinking +
  promptCaching with cache-read price; `haiku_4_5` declares thinking /
  vision / promptCaching with Anthropic cache rates; Claude `temperature`
  removed (incompatible when thinking is enabled).
- Fixture catalogs under `test/fixtures/catalogs/`; ProviderSpec covers
  legacy load without `capabilities` and maps unsupported thinking to
  `InvalidRequestError`.
